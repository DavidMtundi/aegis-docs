# Demo Pack Design

**Status:** APPROVED (execute)  
**Date:** 2026-09-23  

## Goal

Stakeholder can run a clean-env demo without engineering improvisation:

```text
seed script → login console → alert → case → close → audit
```

## Deliverables

1. `aegis/scripts/demo-seed.sh` — bootstrap tenant, customer, account, structuring txs (+ optional geo), print credentials and alert ids  
2. `aegis/docs/runbooks/demo-walkthrough.md` — click path in console  
3. README pointers in `aegis` and `aegis-console`

## Non-goals

New APIs, UI demo panel, CSV import, multi-tenant showcase UI.
